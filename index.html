设计理念

⚙️

真实字节码

源码编译为 .aeo 字节码文件，含 16 字节文件头、常量池与指令流。可经反汇编器 aed 还原助记符，学习编译与虚拟机原理的绝佳样本。

🔢

四类型值系统

运行时采用 Tagged Value 表示 int、double、string、bool 四种类型，整数与浮点运算指令分离，赋值时自动依类型分派。

函数与递归

原生支持自定义函数、参数传递、局部变量与作用域隔离。递归调用通过独立的调用帧（CallFrame）实现，函数表支持前向引用。

🌐

跨平台

字节码一次编译、处处运行。为 Windows、Linux、Android 提供独立运行时环境包，无需安装，开箱即用。

Ae 语言文档

Ae 是一门强类型、支持递归函数的字节码型编程语言。程序由 .ae 源文件构成， 经 编译器 aec 翻译为 .aeo 字节码，最终由 虚拟机 ae 解释执行。 本文档描述 Ae 1.0（字节码版本 1.0，魔数 AeBc）的语言规范与实现。

设计目标：以最少的代码量实现一个"五脏俱全"的语言——具备变量、函数、递归、四则运算、条件与循环， 同时保持字节码格式清晰可读，便于教学与二次开发。整个运行时仅三个 C++ 文件，无第三方依赖。

程序结构

一个 Ae 源文件由若干函数定义与一个可选的 main 块组成。函数必须定义在使用之前的作用域顶层（编译器会预处理建立函数表，故调用可出现在定义之前）。main 块是程序的入口点，其执行完毕后程序终止。

结构示例
// 函数定义（顶层）
func add(a, b) {
    return a + b
}

// 入口块
main {
    prln(add(3, 4))   // 输出 7
}

词法与注释

Ae 的词法分析器（Lexer）定义在 aec.cpp 中，支持以下 Token 类别：标识符、关键字、字面量（整数、浮点数、字符串、布尔值）、运算符与分隔符。

注释

Ae 仅支持单行注释，以 // 开头，直至行末。注释内的内容不参与编译。

示例
// 这是一条注释
prln("代码")  // 行尾注释

标识符

标识符以字母或下划线开头，后可跟字母、数字或下划线：[A-Za-z_][A-Za-z0-9_]*。标识符区分大小写。

字面量

  • 整数：十进制整数，如 42、-7。编译期以 int32 存入常量池。
  • 浮点数：含小数点的数，如 3.14、.5、2.，均按 double 处理。
  • 字符串：双引号或单引号包裹，支持反斜杠转义 \"、\\ 等。
  • 布尔值：关键字 true、false，运行时以整数 1 / 0 表示。

关键字（保留字）

以下标识符被语言保留，不可用作变量或函数名：

func main if else while break continue return local true false pr prln inp

注：pr、prln、inp 虽为内置函数，但在词法层面被识别为标识符，故不严格保留——但强烈建议不要覆盖。

类型系统

Ae 是静态语义、动态存储的强类型语言：每个值在运行时携带类型标签（Tagged Value），运算按类型分派。语言提供四种内置类型：

类型字面量示例说明
int42, -164 位有符号整数（编译期以 int32 存常量池，运行时提升至 int64）
double3.14, .564 位双精度浮点数
string"hello"UTF-8 字符串，以引用计数 shared_ptr 管理
booltrue, false布尔值，底层以整数 0/1 表示

类型与运算

算术与比较运算分为整数与浮点两套指令。当操作数中任一为 double 时，编译器自动插入 ITOD（int→double 转换）并将运算提升为浮点版本；否则使用整数指令。

类型提升
3 + 2        // IADD（整数加法）
3 + 2.0      // 3 提升为 double → FADD
3.14 * 2      // 2 提升为 double → FMUL
隐式转换：仅发生在算术表达式的自动提升中。字符串与数值之间不会自动互转；布尔值在算术上下文中按 0/1 参与计算。

变量与作用域

Ae 采用词法作用域，变量分为全局变量与局部变量两类，各自拥有独立的存储区（全局槽、局部槽）。

全局变量

在 main 块或顶层语句中，首次出现的赋值会自动创建全局变量：

全局变量
x = 10          // 创建全局变量 x
y = x + 5       // 读取全局 x，创建 y
x += 1          // 复合赋值

局部变量

在函数内部，必须使用 local 关键字声明局部变量。局部变量与全局变量、其他函数的局部变量相互隔离：

局部变量
func foo() {
    local x = 100   // 局部变量，仅 foo 可见
    return x
}

参数

函数参数本质上是位于局部变量区前部的局部变量，按声明顺序依次绑定。

特性全局变量局部变量
声明方式首次赋值自动创建local name = expr
作用域整个程序所在函数体
存储全局变量槽（STORE/LOAD_VAR）调用帧局部区（LOCAL_STORE/LOCAL_LOAD）
生命周期程序运行期函数调用期
作用域规则：在函数内访问变量时，优先查找局部作用域，未命中再查找全局。因此局部变量会"遮蔽"同名全局变量。local 只能在函数内部使用，在函数外使用会引发编译错误。

函数

函数是 Ae 的一等组织单元，通过 func 关键字定义。函数拥有独立的参数列表、局部变量区与返回逻辑，并通过调用栈支持递归。

定义

语法
func name(param1, param2, ...) {
    // 函数体
    return value
}
  • 函数必须定义在顶层（main 之外）。
  • 参数与 local 声明均为局部变量，彼此隔离于全局作用域。
  • 支持递归调用：每次调用创建独立的调用帧。
  • return 可返回任意类型值；若缺省，函数默认返回整数 0。

参数与返回值

函数示例
// 阶乘（递归）
func fact(n) {
    if (n <= 1) {
        return 1
    }
    return n * fact(n - 1)
}

main {
    prln(fact(5))   // 输出 120
}
前向引用：虚拟机启动时会对字节码做一次预扫描（preScanFunctions），建立完整的函数表，因此调用可出现在定义之前，无需前向声明。

调用约定

  • 用户自定义函数调用：name(arg1, arg2, ...)，参数数量必须与定义时一致，否则编译报错。
  • 内置函数（pr、prln、inp）调用方式相同，但使用独立的调用指令。
  • 若函数调用作为语句（返回值未被接收），编译器会自动插入 POP 指令丢弃返回值，避免污染操作数栈。

控制流

条件：if / else

语法
if (condition) {
    // 为真时执行
} else {
    // 为假时执行
}

else 分支可选。条件判断使用"真值"语义：bool 的 false、整数 0、浮点 0.0、空字符串均视为假，其余为真。

循环：while

语法
while (condition) {
    // 循环体
}

跳转：break / continue

在循环体内，break 立即退出循环，continue 跳转到下一次迭代的条件判断。两者均通过编译期回填（back-patching）实现跳转地址。

示例
local i = 0
while (i < 10) {
    i = i + 1
    if (i == 5) {
        continue   // 跳过 5
    }
    prln(i)
}

运算符

Ae 的运算符优先级（从高到低）与结合性如下表。表达式采用递归下降分析法解析。

优先级运算符说明结合性
1()括号 / 函数调用—
2-（前缀）一元取负右
3* / %乘除取模左
4+ -加减左
5== != < <= > >=比较左
6= += -= *= /=赋值 / 复合赋值右

算术运算符

  • + - *：加、减、乘。操作数含 double 时自动提升为浮点运算。
  • /：除法。整数除法（IDIV）向零取整；浮点除法（FDIV）得 double。
  • %：取模（仅整数，IMOD）。
  • 一元 -：取负，对栈顶值计算 0 - x。

比较运算符

返回 bool。同样遵循整数 / 浮点分派规则：两侧任一为 double 即采用浮点比较指令（FCMP_*）。

赋值运算符

支持 =、+=、-=、*=、/=。复合赋值会根据左右侧类型自动选择整数或浮点运算，并将结果写回变量。

内置函数

Ae 虚拟机内置三个函数，编号固定（pr=0、inp=1、prln=2），无需定义即可在任意作用域调用。它们通过专用调用指令 CALL（0x02）调用，与用户函数（CALL_FUNC）区分。

函数ID签名说明
pr0 pr(arg1, arg2, ...) 将参数以空格分隔打印到标准输出，不换行。
prln2 prln(arg1, arg2, ...) 同 pr，但末尾追加换行符。
inp1 inp(prompt?) 打印提示（可选）并从标准输入读取一整行，返回 string。遇 EOF 抛错。
打印规则：pr/prln 可接受任意数量、任意类型的参数，按从左到右顺序打印，各项间以空格分隔。string 打印内容，bool 打印 true/false，浮点整数形式（如 3.0）打印为整数字面量。

虚拟机（ae）

虚拟机是 Ae 的运行核心，以 C++ 实现于 ae.cpp，负责加载 .aeo 文件并逐条解释执行字节码。其核心数据结构如下：

  • 常量池（constPool）：存储程序运行期所需的字符串、整数、浮点常量。
  • 操作数栈（stack）：基于 vector 的栈，用于表达式求值与参数传递。栈下溢会抛错。
  • 全局变量区（globals）：动态扩容的槽位数组。
  • 函数表（funcs）：启动时经预扫描建立，记录每个函数的参数数、局部变量数、入口地址与代码大小。
  • 调用栈（callStack）：由 CallFrame 组成的向量，每个帧保存函数 ID、返回地址与局部变量区，实现递归。

值表示

运行时值 Value 通过 ValueKind 标签区分类型，整数与浮点共用一个联合体（i/f），字符串以 shared_ptr<string> 引用计数管理：

运行时值
enum ValueKind { VAL_INT, VAL_DOUBLE, VAL_STR, VAL_BOOL }
struct Value {
    ValueKind kind
    union { int64_t i; double f }
    shared_ptr<string> str
}

函数调用与递归

调用用户函数时，虚拟机：① 从操作数栈按逆序弹出实参；② 创建新的 CallFrame，将参数填入局部变量区前部；③ 压入调用栈，记录返回地址；④ 跳转至函数入口。遇 RET 指令时弹出帧、恢复返回地址。若调用栈为空时执行 RET（顶层返回），其行为等同于 HALT。

启动流程

  1. load()：校验魔数、读取头、填充常量池与字节码。
  2. run()：调用 preScanFunctions() 建立函数表。
  3. 从 pc = 0 开始逐条取指、执行，直至 HALT 或顶层 RET。

工具链

Ae 提供三个独立的可执行程序，全部以单文件 C++ 实现，仅需标准库即可编译。

程序源文件作用用法
aeae.cpp 虚拟机（执行器） ae program.aeo

编译器（aec）

编译流程为单趟递归下降分析 + 两遍代码生成：第一遍解析顶层并收集函数定义（同时编译函数体到独立缓冲区，最终追加到输出末尾），第二遍回填跳转偏移。break/continue 的跳转地址在循环结束时统一回填。

反汇编器（aed）

读取 .aeo 文件，按字节码规范解析文件头、常量池与指令流，输出带地址、助记符与操作数的可读文本，用于调试与教学。支持 // 风格注释回显。

编译（示例，Linux / WSL）

构建
$ g++ -O2 -std=c++17 ae.cpp  -o ae
$ g++ -O2 -std=c++17 aec.cpp -o aec
$ g++ -O2 -std=c++17 aed.cpp -o aed

错误处理

Ae 在编译期与运行期均以抛出异常（runtime_error）的方式报告错误，由 main 捕获后打印到标准错误并以非零状态退出。

编译期错误

  • 语法错误：如缺少括号、期望特定 Token 等，报"语法错误: 期望 …"。
  • 语义错误：未定义的函数、参数数量不匹配、local/return 在函数外使用、跳转跨度超出 int16 范围等。

运行期错误

  • 算术异常：整数 / 浮点除以零、取模除以零。
  • 栈异常：操作数栈下溢（如栈为空时取值）。
  • 作用域异常：在函数外使用 LOCAL_STORE/LOCAL_LOAD。
  • 调用异常：调用未定义的函数、inp() 遇 EOF。
  • 文件异常：无法打开文件、魔数不匹配、文件过短。
错误输出示例
✗ 运行错误: 整数除以零
✗ 编译错误: 未定义的函数: bar
